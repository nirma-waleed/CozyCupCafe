# Cozy Cup Cafe ☕

## Introduction

Cozy Cup Cafe is a simple and interactive cafe website designed to provide visitors with information about the cafe, its menu, and available services. Users can explore different food and drink items, calculate their order total, switch between light and dark modes, and submit feedback through an interactive form. The website is developed using HTML, CSS, and JavaScript as part of a web development assignment.

## Project Overview

Cozy Cup Cafe is a responsive cafe website developed using HTML, CSS, and JavaScript. This project demonstrates front-end web development concepts and JavaScript DOM manipulation through interactive features.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- **Light/Dark Mode:** Toggle between light and dark themes.
- **Dynamic Opening Status:** Displays cafe opening status according to the current time.
- **Interactive Menu:** Highlights menu rows when the mouse moves over them.
- **Menu Filtering:** Filter menu items by All, Drinks, or Pastries.
- **Order Calculator:** Select menu items using checkboxes and calculate the total price.
- **Read More / Read Less:** Show or hide additional cafe information.
- **Feedback Form:** Accept username, email, and birth year.
- **Age and Discount Validation:** Calculate age and display student or senior discount eligibility.
- **Character Counter:** Displays remaining characters in Special Requests, with a maximum limit of 100 characters.
